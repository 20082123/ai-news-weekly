# 06 · 爆款写作规范（发稿前自检）

> 提炼自 `AI Signal/调研/爆款底层逻辑拆解-2026-08-16.md`（真实样本拆解）。
> **任何 agent 替第一用户写平台内容（主线/副线）都必须遵守本规范**；
> 系统内的骨架稿/提示包模板与本规范同源（DEC-023）。

## 总公式

**爆款 = 熟悉素材 ×（心理翻译 + 现实映射 + 结构药方）**

## 五要素（缺一不可）

1. **标题：制造认知失调**。大众的默认理解是什么？找一个「冲突但更真」的解读。
   禁止纯新闻句（「X 改价了」）；立场句或数字+立场；每个数字只有一种解读；
   ≤20 字（小红书）。
2. **开头：情绪考古**。第一人称/直接喊话，两行内让读者认出「这是给我看的」，
   打一个「说不出口的隐痛」（囤课不读/怕落后/省钱焦虑），每篇只打一个。
3. **正文：翻译力**。官方数字/专业概念 → 一句人话金句（对照句最佳）。
   数字只从骨架稿事实清单取，逐字一致。
4. **结尾：抛问题**。必须是问题，不是建议——评论由问题而来。
5. **形态：收藏驱动**。每篇必须回答「读者能带走什么」：清单/对比表/步骤/资源。
   纯观点裸发不做（实测 0-9 赞）。

## 三条铁律（我们的差异化，对标账号做不到的）

- **数字全对**：每个数字有官方出处、只有一种解读；错一个即整条报废；
- **反焦虑立场**：结论是「你不用管」时，把它做进标题——「别慌」是我们的招牌；
- **禁说清单**：骨架稿「终审自查·禁说清单」逐条过，任何一条出现在稿子里 = 不发。

## 栏目固定格式

| 栏目 | 收藏形态 | 标题引擎 | 开头引擎 |
| --- | --- | --- | --- |
| 主线「这周 AI 关你什么事」 | 每周前后对比表 | 认知失调（默认恐慌→冲突真相） | 情绪考古（一个隐痛） |
| 副线「我搭的工具」 | 步骤清单（问题→搭法→踩坑→成品→钩子） | 认知失调（原来不难/原来还能这样） | 第一人称经历 |

## 标题公式库（6 条，每条出 3 个备选再挑）

1. 痛点+方法+结果；2. 身份+场景+收益；3. 数字+方法+回报；
4. 错误动作+正确解法；5. 反常识+解释；6. 立场句（口语+质疑）。

## 广告法底线（最高优先级：国家法律，高于平台规则）

依据《中华人民共和国广告法》。**每一篇内容都按「这就是一条广告」来审**——
小红书带货/种草内容受广告法与《互联网广告管理办法》约束，我们宁可从严：

1. **第九条 · 绝对化用语**：禁用「国家级/最高级/最佳/第一/顶级/唯一/最便宜/
   百分百」等一切绝对化表述——替换成「官方数据：27 元」这类可核数字；
2. **第四条 · 真实不误导**：不得含有虚假或引人误解的内容——标题的「认知失调」
   必须来自真实可兑现的数字，编冲突 = 虚假宣传；
3. **第十一条 · 引证有出处**（我们的护城河的法律版）：使用数据、统计资料、
   引用语必须**真实、准确、表明出处**——这就是「每个数字有官方来源、链接可查」
   的法律要求，缺出处的数字不写；
4. **第十三条 · 不贬低同行**：对比内容（如与 GPT 比价）只摆数字、不给
   「某某更差/更坑」的定性结论；
5. **第二十五条 · 不承诺收益**：招商/投资类不得对未来收益作保证性承诺——
   副业/搞钱类内容一律不说「月入 XX」「稳赚」；
6. **医疗/保健特殊条款**：不碰疗效、健康功效类表述（AI 医疗新闻只转述官方）。

## 平台红线（违反 = 限流/下架/封号，与数字纪律同级）

依据：小红书《社区公约 2.0》（2026-01，真实分享、反对虚假人设/制造对立/虚假营销）
与 AI 治理新规（2026：AI 生成内容须主动标识）。逐平台维护，小红书现行八条：

1. **真实人设**：不用 AI 虚拟人冒充真人；不假装「本人亲测」未经测试的体验
   （needs_testing 封印同源）；
2. **AI 生成标识**：AI 生成的图/视频必须主动标注（封面或正文注明）；我们文字
   由人终审、官方截图属事实引用——**AI 出品的背景图必须标注**；
3. **广告法禁词**：无「最/第一/国家级/顶级/唯一/绝对」等绝对化用语
   （禁说清单的「最强/必装」即此类，扩展到全平台）；
4. **零引流**：不留微信/QQ/群/手机号、不引导私信领资料；「链接放评论区」只限
   公开信息源（GitHub/官网），不导流任何私域；不卖课、不收徒、不承诺收益
   （承诺收益即投资类红线，副业内容尤其小心）；
5. **医疗/金融/投资**：不解读个股、不给健康结论；AI 医疗新闻只转述官方表述；
6. **时政/新闻资质**：不做时政评论，内容保持在「工具与学习」范围内；
7. **不侵权**：官方截图 = 事实引用，需标来源；不搬运他人图文，封面不盗图；
8. **不诱导互动**：不搞「关注+点赞抽奖」；结尾抛问题是引发讨论，不是诱导。

## 发稿前自检清单（agent 逐项打勾后交用户终审）

- [ ] 五要素齐（标题失调/开头考古/正文翻译/结尾提问/形态可收藏）
- [ ] 受众匹配自查通过（②落在学生/普通年轻创作者头上）
- [ ] 每个数字只有一种解读，且与事实清单逐字一致
- [ ] 禁说清单零命中；无「最强/必装/暴涨」类无出处表述
- [ ] 个人数据（我花了 X 小时、我收藏 N 个）留空让用户填真实值，agent 不代编
- [ ] 标题 ≤20 字；标签含人群词；来源链接标注「放评论区」
- [ ] **广告法六条逐项过**（最高优先级：绝对化用语/真实不误导/引证有出处/
      不贬低同行/不承诺收益/不碰医疗保健）——缺出处的数字不写
- [ ] **平台红线八条逐项过**（广告法禁词 / AI 生成标识 / 零引流 / 不承诺收益 /
      不制造对立 / 不侵权 / 不诱导互动 / 不碰医疗金融时政）
- [ ] **过 humanizer 去 AI 味**（防平台 AI 检测限流）：去 emoji 小标题结构、
      破三连排比、去「不是X是Y」负面排比、金句标签融进正文、句子长短打散；
      保留小红书语感（白嫖/吃灰这类词），emoji 不装饰段落标题
